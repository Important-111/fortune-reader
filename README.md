# 遇事不决，全靠玄学 · 个人运势解读小工具

一个纯前端、无需后端的单页应用，根据用户填写的个人资料，以**确定性可复现**的算法推演出「今日 / 本周 / 本月 / 今年」四个时间维度的运势，并提供总体评分、吉凶等级、幸运色数字、宜忌清单与五个领域（事业 / 财运 / 感情 / 健康 / 学业）的提示。

数据全部在本机（浏览器）计算，不上传任何服务器。结果仅供娱乐参考。

---

## 一、如何运行

项目为纯静态前端（HTML + CSS + 原生 JavaScript），无任何构建依赖：

1. 直接用浏览器打开 `index.html`；或
2. 在项目目录启动任意静态服务器后访问：

```bash
cd fortune-reader/main
# 任选其一
python3 -m http.server 8080
# 或
npx serve .
```

然后访问 `http://localhost:8080` 即可。

## 二、功能说明

### 表单输入
- **必填建议**：出生日期（公历），提供了即可进行基础推演；同时会**自动推算星座**。
- **可选**：姓名、性别、出生时辰、星座（可手动覆盖）、血型、MBTI、出生地。
- **出生地**（可选，覆盖全国主要城市）：仅作**方位五行**参考（东方木、南方火、西方金、北方水、中原土），填写后会参与个人化种子与小幅方位加成，并在结果页概览中展示（如「北京（北方 · 水）」）；因表单时辰粒度为 2 小时，不做严格真太阳时校正。**未填则完全不影响既有结果**，按北京时辰推演。
- 支持只填一部分资料，填得越全，推演纳入的维度越多、文案越丰富。

### 时间维度
- 今日、本周、本月、今年，可随时切换查看对应运势。每一维度的结果由「稳定的个人种子 + 该维度时间锚点」唯一确定，切换与刷新不会改变结果。

### 一事专断（可选）
- 在整体运势之外，可针对某一件具体事情做**专项运势**解读。用户既可选择事项分类（工作/事业、财运/投资、感情/姻缘、健康/出行、考试/学业、洽谈/合作、搬家/置业、其他），也可填写一句具体事项（如“下周要不要跳槽”）。分类与文字二者取其一即可，**均可留空**——留空则仍只出整体运势。
- 填写具体事项后，结果区会在整体运势之上新增一张「一事专断」卡片，展示这件事在**当前选中时间维度**下的专属吉凶等级、专属指数、宜做建议、忌做建议，以及一句口语化的倾向性结论（例如“此事可做，但宜缓不宜急”），帮助用户快速读懂“这件事”在这一时间维度下的吉凶与取舍。
- 切换时间维度页签时，该卡片会同步切换为对应维度的专项结果。

### 求签 / 摇签筒（新增）
- 独立于整体运势的**签筒**区块，可选择求签维度（今日 / 本周 / 本月 / 今年，默认跟随当前选中页签），也可不选默认今日。
- 点击「求签」会从签筒（含 108 支签）中抽出一支，展示**签号**（如第 108 签）、**古典签题**（二字/四字，如「鸿鹄得志」「蟾宫折桂」）、**签等级**（上上签 / 上吉 / 中吉 / 中平 / 下下签）、**古典七言签诗**，以及对标知名寺庙灵签（杭州灵隐寺、厦门南普陀、四川峨眉等《灵签》体系）的**签文解析**板块与一句**白话点睛**。
- **签文解析（解签板块）**：每支签都附有八项吉凶解析（家宅 / 求财 / 婚姻 / 功名 / 疾病 / 失物 / 行人 / 诉讼），各签解析内容与该签的等级、主题、签诗意象严格对齐——上上签则家宅兴旺、财源广进、姻缘和合；下下签则宜守戒躁、谨防是非，语言典雅庄重，贴近寺庙解签口吻。
- 求签结果采用「稳定签」：同一人、同一维度、同一天抽到**同一支签**，可复现；若想换换手气，可用「换个手气 · 随手再抽一签」按钮，结果每次点击都不同（仅供娱乐）。
- **来源注明**：签筒中的 108 支签诗与签文解析均为本工具开发时**原创编写的娱乐文本**，结构参考知名寺庙灵签的解签格式再创造，并非任何真实签谱原典，仅供娱乐。

### 答案之书（新增）
- 一个「翻书 / 提问」控件。用户可以心里想一个问题（也可在输入框里写下来显示在答案上方，留空只出答案）。
- 点击「翻开答案之书」，随机显示一句口语化短句（肯定 / 否定 / 含糊 / 建议式，类似 Magic 8-Ball 的中文版，已扩充至 300 条）。
- 答案之书本性就是「随手翻」，因此**每次点击都会出新答案**，连续两次也不同，不会显得僵化。
- **来源注明**：答案之书的 300 条回答同样为本工具开发时**原创编写的娱乐短句**（参考占卜翻书玩法再创造，扩充至 300 条以对标常见纸质《答案之书》的容量），并非任何既有魔法书或书籍原文，仅供娱乐。

### 输出内容
- 总体运势评分（0–100）与等级（大吉 / 吉 / 平 / 凶 / 大凶）。
- 幸运色、幸运数字、当期干支。
- 「宜」做之事与「忌」做之事的清单。
- 事业、财运、感情、健康、学业五领域分别的评分与文字提示。
- 所有文案采用**偏口语化、带具体生活场景**的风格表达（如总结话术、宜忌清单、领域提示均谈人话、接地气）。

## 三、推演规则（可复现算法）

**核心思路**：所有结果都由「稳定种子」通过可复现的伪随机序列生成。只要个人资料与目标时间维度锚点不变，结果就永远一致。

### 1. 个人稳定种子
将姓名、性别、出生资料、星座、血型、MBTI 拼接后，用 **FNV-1a 32bit** 散列得到单值。出生资料中的日期与时辰构成唯一键，因此——

> 只要资料不变，个人种子恒定；改资料才产生新的命运线。

### 2. 时间维度锚点
- 今日 → `D-年-月-日`
- 本周 → 本周一的日期 `W-...`
- 本月 → `M-年-月`
- 今年 → `Y-年`

把「个人种子」与「维度锚点散列」用整数混合算法（`mixSeeds`）得到**最终种子**。

### 3. 伪随机可复现
以最终种子初始化 **mulberry32** 生成器。同种子必产生相同随机序列 → 运势结果可复现。

### 4. 各命理要素的加权融合
- **四柱八字**：由公历生日推当日的干支（以 1900-01-01 甲戌日为基准起序），取日干五行影响基调。
- **紫微斗数（简）**：填了出生时辰才计入，以「命宫/出生时辰地支」做一个小幅加成。
- **六爻 / 梅花易数（简）**：以「年 + 月 + 日」数字之和取 8 的余数作为卦数，影响 ±6 分。
- **星座**：映射火/土/风/水四元素，火、土倾向略加分。
- **血型**：A/B/AB/O 的能量值修正。
- **MBTI**：16 型各自的进取/稳健倾向修正。
- **出生地方位五行（可选）**：按城市相对中原的方位取五行（东方木主生发、南方火主炎上、西方金主肃敛、北方水主智藏、中央土主厚载）做小幅加成；仅当填写出生地时才生效并入种子，未填写用户的种子与结果与旧版完全一致。

这些因子在线性加权后越界钳制到 `[8, 98]`，再取整得到 0–100 运势分。

### 5. 评级与清单
- ≥85 大吉 / ≥70 吉 / ≥50 平 / ≥35 凶 / 其余大凶。
- 高评级 → 「宜」项多、「忌」项少；反之亦然。
- 五领域评分在总分之附近加入各领域自己的随机波动（仍可复现）。
- 总结话术、宜忌清单与五领域提示均为**偏口语化文案池**，按等级/科目从同一可复现随机序列取样，不引入随机数以外的其他不确定来源，因此「同输入同结果」不变。

### 6. 一事专断（独立推演分支）
「一事专断」是**一条完全独立于整体运势的新推演分支**，遵循同样的确定性原则，且**不会改动整体运势的任何结果**：

- 基础复用同一份**个人稳定种子** `computePersonalSeed(profile)`（与整体运势的用户可复现基础完全一致）。
- 事项种子 = `mixSeeds(个人种子, hashString(事项文本+'@'+分类), hashString(时间维度锚点))`，再以它 `new` 出**另一个独立的 mulberry32 rng**。
- 因为使用独立的 rng，一事专断对随机数的消耗顺序与整体运势 `buildFortune` 的 rng **完全隔离**，因此原有整体运势的评分/等级/文案逻辑与既有 rng 次序**一字未动**，历史结果可复现性不受破坏。
- 文案按事项分类映射到对应话术池（宜/忌/总结各若干条），延续整体运势的口语化、接地气风格。倾向性结论（宜大于忌 / 宜中带忌 / 偏慎）由专属评分推出。

### 7. 求签（独立娱乐分支，确定性）
「求签」同样是**一条完全独立于整体运势与一事专断的新分支**，同样复用同一份个人稳定种子 `computePersonalSeed(profile)`：

- **稳定签**：种子 = `mixSeeds(个人种子, hashString('lottery@' + 维度锚点))`，再以此 `new` 出**另一个独立的 mulberry32 rng**，从签筒（108 支签）中抽取。因此同一人、同一维度、同一天会抽到**同一支签**，可复现。
- 因为使用独立 rng，求签对随机数的消耗顺序与整体运势 / 一事专断的 rng **完全隔离**，绝不改动既有逻辑与 rng 次序。
- **随手再抽一签（随机签）**：以当前时间戳毫秒（`Date.now()`）与 `Math.random` 混合作为种子，`new` 出一次性的 rng 再抽一支，每次点击都不同，仅供娱乐，同样不触碰既有 rng。

### 8. 答案之书（随机，无固定种子）
答案之书本性就是「随手翻」，因此刻意**不采用固定可复现种子**：

- 每次点击都直接用 `Math.random` 从答案池（300 条口语化短句）中抽取，并做「避免与上一次完全相同」的轻量重试，保证每次翻开都是新的一页、不显僵化。
- 与整体运势、一事专断、求签的 rng **完全无关**，不影响任何既有结果的可复现性。
